# Approved seasonal treatment

This applies the existing approved E1 rule from the pixel-art style guide to
the current grass and tree-canopy artwork. It adds no silhouettes or ramp
families. The `seasons` command renders the same Town and mountain scenes in
all four seasons at 16 and 32 px.

Spring uses a shared multiplier moving Grass base 20% toward Grass highlight;
autumn uses one moving Grass base 20% toward Fruit base. Winter moves ramp
colours 30% toward their luminance grey. Summer retains the accepted base
pixels. Ground motifs, tree trunks, fruit, shadows, rock, water and existing
snow cover keep their current art. The world still decides where snow exists.

- Settings is easier to read. Each group of Game settings sits in its own box,
the scrollbar no longer touches the drop-downs, and the model call count and
limit have their own box on the World page. Several settings use shorter
wording. UI Scale now offers named sizes, Small, Medium, Large and Extra
large, and lists only the sizes that fit the screen; Automatic picks Medium on
a 1080p screen. Render Resolution is removed, so the game always draws at the
screen's own resolution.

# Agents list, Event Log and controls list

Pending for the lists pull request. No Windows playtest is claimed.

- Open Agents in a world with hungry, cold or ill agents and some who have died. Living agents come first with their activity and the right tags; click a row to find the agent and double-click to open their Profile.
- Open the Event Log after some time has passed. Each day has a heading, each row an icon, new rows a dot, and located events a Find button that moves the camera without touching the scrollbar.
- With many agents or events, both panels stop above the bottom of the screen and scroll, including after resizing the window.
- Press F1 in both themes. Keys are keycaps with the letter centred, and the list does not cover the clock in the top bar.

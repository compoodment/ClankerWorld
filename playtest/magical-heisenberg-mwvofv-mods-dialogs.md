# Mod Library, confirmations and status messages

Pending for the Mod Library and dialogs pull request. No Windows playtest is claimed.

- Open the Pause Menu's Mod Library in a world with an agent-proposed add-on, in both themes. Each add-on is a card with its name, the proposer's portrait and name, its version and a status tag; the internal package name does not appear. In a world with none it says nothing has been added yet.
- Open Quit to Menu, Delete World and a save's Delete confirmation in both themes. The message is centred, Cancel and the action sit together, names have straight quotes with no wide gaps, and the close button is a framed button inside the frame, level with the title.
- Cause a good result, such as saving a key, and a problem, such as a lost connection. The message has a tick or a warning sign, its words are plain ink, a short message has a small box and a long one wraps.

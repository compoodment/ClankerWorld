- On Windows, with the game running its own world server: open **Settings**, choose **Report a problem**, and check that File Explorer opens with the new zip selected in `%LOCALAPPDATA%\ClankerWorld\reports`. Open the zip and check it has `summary.txt` with the game version, Windows version, graphics card and open world, plus `logs\game.log` and `logs\host.log`, and that no key you entered appears anywhere in it. ([#1260](https://github.com/compoodment/ClankerWorld/issues/1260))

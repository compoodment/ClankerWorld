# Saved worlds checked at server start

Pending after merge from [#625](https://github.com/compoodment/ClankerWorld/issues/625).

- On the paired world: with several saved worlds, including a Medium one, restart the server, wait a minute, then open Load World. The list appears almost at once, with every world and the same marks as before. ([#625](https://github.com/compoodment/ClankerWorld/issues/625))
- On the paired world: restart the server and play straight away. The world runs and saves normally while the server checks the saved worlds. ([#625](https://github.com/compoodment/ClankerWorld/issues/625))

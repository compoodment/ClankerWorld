# Continuity rule counts eligible couples

PR for [#1329](https://github.com/compoodment/ClankerWorld/issues/1329).
Automated runtime, replay and native UI checks are separate from these pending
Windows checks. The four-couple threshold remains provisional for playtesting.

- [ ] In a started world, add enough unpartnered adults to reach eight people. The continuity warning stays on. Form four eligible adult partnerships through normal choices: the rule turns off and the Event Log explains the count. If a partner dies or becomes an elder, the rule turns on again below four couples.
- [ ] Below the threshold, inspect a partnered adult's choices and model explanation: it gives the eligible-couple reason and allows postponement for two world days. Partnership choice stays voluntary. At the deadline, the existing preparation, caregiver, home and food requirements still apply.
- [ ] Save and reload while the rule holds a couple, then resume. Its deadline stays the same and the Event Log does not repeat a transition. A couple caring for an infant still counts toward the threshold, but does not receive another two-day child deadline while the infant needs care.

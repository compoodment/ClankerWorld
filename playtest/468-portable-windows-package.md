- On a Windows 11 x64 PC with no repository checkout or .NET install, download the `clankerworld-windows-11-x64-portable` CI artifact, unzip it and start `ClankerWorld.exe`. The Main Menu opens without asking for a server address or a comparison code. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- With the game open, check `%LOCALAPPDATA%\ClankerWorld`: it holds `saves`, `settings` and `logs\host.log`, and the game folder gains no save files. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- Add a key on the masked key screen, create, place and start a world, pause, save, then choose Quit Game. The game closes after "Saving your world…", and no ClankerWorld.Viewer process is left in Task Manager. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- Start the game again with the network to the private server unplugged or blocked. Continue opens the same world at the saved point, and your fullscreen and UI scale settings are kept. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- While the game is open, run `netstat -ano | findstr 5188` in a command prompt. The world server listens only on 127.0.0.1. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- End the ClankerWorld.Viewer process in Task Manager while playing, then start the game again. It starts a new world server and reopens the world from its last saved tick. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- End the ClankerWorld.exe process while playing, then start it again. Model calls stop within a few seconds of the crash, and the new game uses the server that was left running. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- Search `logs\host.log` and the game folder for your key. It appears nowhere. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))
- Unzip a second copy of the package into another folder and start it. It opens the same worlds, because they live in your user folder, not the game folder. ([#468](https://github.com/ClankerWorldOrg/ClankerWorld/issues/468))

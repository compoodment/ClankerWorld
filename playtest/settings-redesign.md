# Settings redesign and automatic interface size

Pending for PR #585, a direct owner request. No Windows playtest is claimed.

- Open Settings from the Main Menu and from the Pause Menu. Interface, Display, Weather and Date and time each sit in their own box, there is no UI Scale or Render Resolution setting, and the scrollbar does not touch the drop-downs. ([#585](https://github.com/compoodment/ClankerWorld/pull/585))
- On a 1080p or 1440p screen the interface shows at 200%; drag a windowed game down to 1280×720 and it switches to 100% without anything going off screen. Letters stay crisp at both sizes. ([#585](https://github.com/compoodment/ClankerWorld/pull/585))
- In a world, switch Settings between Game and World. The menu keeps its width, each page opens at its top, and the model call count and limit sit in their own Model calls box after Agent model. ([#585](https://github.com/compoodment/ClankerWorld/pull/585))

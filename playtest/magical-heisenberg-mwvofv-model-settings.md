# Agent model settings and Add an agent

Pending for the model settings pull request. No Windows playtest is claimed.

- Open an agent's Profile, then **Model**, in both themes. The fields are captioned Provider, API key and Model, a long key name is cut short instead of widening the panel, and there is no sideways scrollbar.
- On that page, **Open model settings** opens World Settings at the Agent model box with the same agent chosen. **Delete this key** is offered there for a named key, not on the agent's page.
- Open **Add Agent**. The fields have the same captions, and under a line with a mouse icon it says "Click on land to place them. Point first to see which household and Town they would join."
- Point at a House, at Town land with no household and at land outside any Town. The hint says who they would join, or that they would start their own household. Where property or borders overlap, it says to choose another tile.

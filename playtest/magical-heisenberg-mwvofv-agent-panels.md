# Memories, Family Tree and Profile

Pending for the agent panels pull request. No Windows playtest is claimed.

- Open an agent's Profile in both themes. The Model line reads like "Model: OpenAI · Ready", with no "chosen by". When Jev makes a choice for them, the Profile says "Jev made their latest choice."
- The thoughts box shows only the newest thought, in at most two lines. Clicking it or **Read all** opens every recent thought.
- People shows a heart for a partner, a figure for parents and children, a house for their household and a small meter for trust. Suggest and Order sit together in one switch, and "Say something..." has its dots on the baseline.
- Open **Memories** for an agent with memories, beliefs and map records. Each tab shows only its kind with a count; beliefs show how sure the agent is, private memories have a Private tag, and map places show a picture of the ground. A long list scrolls without running off the screen.
- Open **Family** for an agent with a partner and a child, and for one with no family. The tree fits its people and opens beside the Profile, partners have a heart between them, only the dead are marked "died", and with no family it says housemates are not relatives.

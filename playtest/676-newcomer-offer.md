# Add a newcomer

- On the paired world: start a disposable world with fewer than eight living agents who are not elders. Open Event Log and choose **Add a newcomer**. The usual Add Agent controls should open; nobody should be added and the paid-call count should stay unchanged until you choose an explicit paid action. ([#676](https://github.com/compoodment/ClankerWorld/issues/676))
- Add enough adults to reach eight living non-elders, then let the world advance. The Event Log's newcomer offer should disappear. If the population later falls below eight, the offer should return. ([#676](https://github.com/compoodment/ClankerWorld/issues/676))

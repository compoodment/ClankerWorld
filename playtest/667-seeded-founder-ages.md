# Seeded founder ages

Pending after merge from [#667](https://github.com/compoodment/ClankerWorld/issues/667).

- Create a new world, place the four founders and open each agent card. Each shows an adult age between 15 and 25 days, such as **Adult · 19 days**, and no two founders show the same age. ([#667](https://github.com/compoodment/ClankerWorld/issues/667))
- Create another world with the same seed and place four founders. They show the same ages in the order you placed them. ([#667](https://github.com/compoodment/ClankerWorld/issues/667))
- Start World and use Add Agent a few times. Each new adult's card shows an age between 15 and 25 days, and saving and loading keeps every age. ([#667](https://github.com/compoodment/ClankerWorld/issues/667))
